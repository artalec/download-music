# Hitmoz Downloader

Нативное приложение для macOS: поиск треков на `ru.hitmoz.org` и их скачивание в один клик.

## Сборка локально

```bash
swift build -c release
swift run -c release
```

## Сборка через GitHub Actions

Каждый пуш в `main` автоматически запускает сборку. Готовый `.zip` с `HitmozDownloader.app` появится в разделе **Actions → (последний запуск) → Artifacts**.

Чтобы создать релиз, добавьте тег:

```bash
git tag v1.0.0
git push origin v1.0.0
```

Архив автоматически прикрепится к GitHub Release.

## Установка

1. Скачайте `HitmozDownloader.zip` из артефактов.
2. Распакуйте и перетащите `HitmozDownloader.app` в `Applications`.
3. При первом запуске macOS может сказать, что разработчик не подтверждён.
   Обойти: **правый клик по .app → Открыть → Открыть**.

## ⚠️ Дисклеймер

Приложение работает как парсер публичных страниц сайта. Скачивание музыки может нарушать авторские права — используйте только для треков, которые разрешено скачивать.
